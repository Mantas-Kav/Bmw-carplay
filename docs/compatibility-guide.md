# Firmware compatibility guide

This is a **research guide**, not a promise that a specific vehicle can be activated.

A third-party compatibility table reports that:
- J–M: USB and ENET activation offered, split-screen reported.
- N–O: USB and ENET activation offered, full-screen reported.
- P–Y: ENET activation offered, USB activation not offered, full-screen reported.

Some providers differ on edge versions and prerequisites. Treat these as vendor claims rather than universal rules. Hardware, Wi-Fi antenna/port, licensing status and software modifications can change outcomes.

Source: https://autonavi.ee/tarkvaraversiooni-juhend/?lang=en
